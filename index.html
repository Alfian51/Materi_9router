BAB 1 · LATAR BELAKANG MASALAH

Kenapa Antigravity Sering Kena Limit?

Sebelum bicara solusi, kita harus paham dulu masalahnya. Ini kunci kenapa 9Router dan OpenCode dibutuhkan.

🎫

Apa itu Token?

Model AI tidak membaca kalimat utuh. Teks dipecah menjadi satuan kecil bernama token (kurang lebih = potongan kata / karakter). Semakin panjang prompt-mu, semakin banyak token yang dikonsumsi.

⏳

Apa itu Rate Limit?

Layanan AI gratis memberi batas pemakaian per jam / per hari. Kalau kuota token habis, muncul error Rate Limit Exceeded atau Quota Reached — AI berhenti merespons.

🧪

Contoh Skenario Nyata

Kamu sedang minta Antigravity membuat Navbar untuk website portofolio. Baru separuh jalan, token habis → error → pekerjaan macet. Harus menunggu reset kuota atau ganti akun. ❌

❌ "Rate Limit Exceeded" / "Quota Reached" — Antigravity berhenti merespons, pekerjaan terhenti di tengah jalan.

💡 Inti masalahnya

Antigravity gratis bergantung pada satu sumber token yang terbatas. Kalau sumber itu habis, tidak ada jalur cadangan — kerja langsung berhenti. Solusinya: sediakan jalur AI cadangan lewat sistem perantara yang bisa mengalihkan permintaan ke provider lain. Sistem perantara itu bernama 9Router, dan sumber token cadangannya bernama OpenCode.

BAB 2.1 · PEMBAHASAN UTAMA

Apa itu 9Router?

Pahami tiga hal ini dulu: definisi, alasan memakai, dan fungsinya. Setelah itu baru masuk ke cara kerja teknisnya.

Definisi 9Router

9Router adalah aplikasi lokal yang berjalan di komputer kamu sendiri (bukan di cloud/server orang lain). Ia bertugas menjadi gateway — gerbang perantara — bagi semua permintaan AI yang keluar dari editor coding seperti Antigravity. Semua prompt yang kamu ketik tidak langsung menuju provider AI, melainkan lewat 9Router dulu.

  • Berjalan di port default 20128 → http://localhost:20128
  • Harus di-install dan dijalankan di CMD (Command Prompt)
  • Punya dashboard Web UI yang dibuka lewat browser
  • Bertindak seperti "polisi lalu lintas AI" — menentukan request menuju provider mana
  • Menyimpan log semua request yang masuk, untuk monitoring pemakaian

Kenapa Kita Harus Menggunakan 9Router?

9Router tidak sekadar "alat tambahan". Ia memecahkan masalah yang paling sering memutus alur kerja saat ngoding pakai AI.

🛡️

Anti-Macet saat Limit

Tanpa 9Router, satu provider limit = kerja berhenti total. Dengan 9Router, request otomatis dialihkan ke provider lain yang masih sehat. Produktivitas tidak pernah putus.

🧩

Satu Pintu, Banyak Model

9Router menggabungkan banyak provider dan model (Claude Sonnet, Claude Opus, Gemini, dll) lewat konsep Combo. Kamu pilih model cukup sekali di dashboard, bukan di sana-sini.

📊

Kontrol & Log Lengkap

Semua request tercatat: model apa yang dipakai, berapa banyak token, provider mana yang merespons. Pemakaian jadi transparan dan mudah dipantau.

🔌

Jembatan ke Antigravity

9Router menyediakan MITM Server dan API Key khusus sehingga Antigravity bisa terhubung secara resmi. Editor tetap dipakai seperti biasa, tapi sumber AInya lebih banyak.

BAB 2.2 · PENYEDIA TOKEN

Apa itu OpenCode?

9Router hanya pengatur lalu lintas. Yang benar-benar menjalankan AI dan mengeluarkan kode adalah provider — dan salah satu provider token yang kita pakai adalah OpenCode.

Definisi OpenCode

OpenCode adalah platform online (berbasis website di https://opencode.ai) yang menyediakan token API untuk mengakses model AI seperti Claude Sonnet, Claude Opus, dan lainnya. Berbeda dengan 9Router, OpenCode tidak perlu di-install dan tidak perlu dijalankan di CMD. Cukup buka browser, daftar akun, login, lalu buat API Key.

  • Berbasis website — akses lewat browser, tanpa install
  • Menyediakan API Key (format: sk-xxx-yyy-zzz-...)
  • Ada paket Free / Ready to Use — cocok untuk belajar
  • API Key di-paste ke dashboard 9Router → langsung terhubung
  • Lebih stabil dibanding akun Antigravity gratis biasa

Kenapa Kita Ambil Token dari OpenCode?

Pertanyaan paling penting: kenapa tidak langsung pakai token acak? Berikut alasannya secara lengkap.

🎟️

API Key = Tiket Akses

Model AI tidak bisa dipanggil tanpa izin. API Key dari OpenCode adalah tiket resmi yang membuktikan kita berhak memakai model-model di dalamnya. Tanpa key, 9Router tidak punya cara memanggil AI.

🔓

Kuota Lebih Lega

Akun Antigravity gratis mudah kena rate limit. Token dari OpenCode memberi jalur pemakaian sendiri yang lebih stabil, sehingga kerja tidak gampang terputus di tengah jalan.

🧠

Akses Banyak Model

Dari satu platform OpenCode kita bisa memilih berbagai model — Claude Sonnet, Claude Opus, dan lainnya — tanpa harus membuat akun di banyak tempat.

🌐

Online & Simpel

Prosesnya ringan: buka opencode.ai → Sign Up → verifikasi email → login → buat API Key → copy. Tidak ada proses instalasi yang berat.

🔗

Paste Sekali, Dipakai Terus

Setelah key di-paste ke menu Providers di 9Router dan statusnya Connected, seluruh request dari Antigravity otomatis memakai key tersebut. Sekali setup, selesai.

✅

Ready to Use

OpenCode menyediakan layanan gratis yang langsung siap pakai — sangat cocok untuk praktikum dan tugas sekolah tanpa biaya.

⚠️ PENTING: API Key OpenCode hanya ditampilkan SATU KALI saat dibuat. Begitu layar tertutup, key tidak bisa dilihat lagi — harus membuat key baru. Jadi langsung copy dan simpan ke file opencode-api-key.txt, jangan dibagikan ke siapa pun.

BAB 3 · PRAKTIK LANGSUNG

Instalasi & Setup Lengkap

Ikuti urutan langkah dari 0 sampai 8, jangan loncat. Estimasi total 30–45 menit.

0

Install Node.js: Langkah Pertama yang Paling Penting!

Apa itu Node.js? Node.js adalah runtime environment yang membuat laptop bisa menjalankan aplikasi JavaScript di luar browser. 9Router dibangun dengan Node.js — jadi wajib install dulu. Tanpa Node.js, 9Router tidak bisa dijalankan.

  1. Buka nodejs.org → pilih versi LTS (Long Term Support).
  2. Download installer Windows → filenya bernama node-v18.xxx.msi atau node-v20.xxx.msi.
  3. Klik installer: Next beberapa kali → pilih I Accept untuk terms & conditions.
  4. ⚠️ PENTING: centang Add to PATH agar Node.js bisa diakses dari CMD → klik Install → tunggu 5–10 menit.
  5. Restart laptop — penting agar PATH aktif.
  6. Verifikasi: buka CMD baru lalu ketik:
node -v
npm -v

✅ Jika keluar versi (misal v18.17.0 dan npm 9.6.4) → Node.js berhasil terpasang!

1

Install 9Router Secara Global

Pastikan Node.js sudah terpasang. Di Command Prompt, ketik perintah berikut lalu Enter:

npm install -g 9router

Tunggu sampai proses selesai — ditandai munculnya tulisan added packages.

2

Jalankan 9Router & Buka Web UI

Di Command Prompt, ketik:

9router

Akan muncul menu pilihan: Web UI (Open in Browser), Terminal UI (Interactive CLI), Hide to Tray (Background), dan Exit. Pilih opsi pertama: Web UI (Open in Browser).

✅ Browser terbuka otomatis ke dashboard 9Router.

3

Login ke Dashboard 9Router

Dashboard akan meminta password. Masukkan password default:

123456

✅ Jika berhasil, kamu masuk ke halaman utama 9Router.

3B

Ambil API Key dari OpenCode

Sebelum menghubungkan OpenCode ke 9Router, kita harus membuat dan mengambil API Key OpenCode dulu. Ikuti urutannya:

  1. Buka browser → masuk ke opencode.ai.
  2. Klik Sign Up / Register (jika belum punya akun): isi email, password, nama (opsional) → Create Account.
  3. Verifikasi email: OpenCode mengirim email → buka → klik link verifikasi.
  4. Login: buka opencode.ai lagi → Sign In → masukkan email & password.
  5. Cari menu API Keys / Settings: bisa di sidebar kiri (Settings, API Keys, Integrations) atau di ikon profil kanan-atas.
  6. Klik + Create API Key / + New / + Generate → isi nama key, misal Antigravity atau 9Router → klik Create / Generate / Save.
  7. Copy API Key segera — key muncul satu kali saja (format sk-xxx-yyy-zzz-...).
  8. Simpan ke Notepad dengan nama opencode-api-key.txt. Jangan bagikan ke siapa pun.
⚠️ API Key hanya ditampilkan SEKALI. Tidak dicopy sekarang = tidak bisa dilihat lagi, harus buat key baru.
4

Connect OpenCode ke 9Router

Di dashboard 9Router, buka menu Providers (atau Endpoint & Key):

  1. Pilih menu Providers.
  2. Cari / tambah provider OpenCode.
  3. Masukkan API Key OpenCode yang sudah dibuat sebelumnya.
  4. Klik Connect / Save.

✅ Jika berhasil, status OpenCode berubah menjadi Connected (hijau).

5

Buat Combo "OpenCode-AI"

Combo adalah konfigurasi AI yang menggabungkan Provider + Model. Langkahnya:

  1. Buka menu Combo & Vision Adapter di dashboard 9Router.
  2. Klik tombol + Create Combo (warna orange/merah).
  3. Isi konfigurasi: Combo Name: OpenCode-AI · Provider: OpenCode · Model: pilih salah satu (misal Claude Sonnet / Claude Opus / dll).
  4. Klik Create / Save Combo.

✅ Combo "OpenCode-AI" berhasil dibuat. Combo inilah yang nanti dipilih di Antigravity.

6

Buat API Key 9Router (untuk Antigravity)

Antigravity memerlukan API Key dari 9Router agar bisa terhubung. Caranya:

  1. Di dashboard 9Router, buka menu Endpoint & Key.
  2. Klik + Create API Key / + New.
  3. Isi nama API Key, contoh: Antigravity-Key.
  4. Klik Generate / Create → copy key yang dihasilkan. Contoh format: sk-da27a8dd47d3696cc-ukrjjx-626c23b3.
⚠️ Simpan API Key ini — akan dipakai di Langkah 7!
7

Setup Antigravity di CLI Tools: Model Selection

Sekarang kita hubungkan Antigravity lewat menu CLI Tools dan pilih model yang dipakai.

  1. Di dashboard 9Router, buka menu CLI Tools.
  2. Pilih Antigravity dari daftar tools yang tersedia.
  3. Paste API Key dari Langkah 6 di field API Key → setelah itu klik Start Server.
  4. Klik Antigravity, lalu pilih model:
    • Opsi A: centang checkbox Select All untuk memakai semua model.
    • Opsi B: centang model tertentu saja — contoh: Claude Sonnet, Claude Opus, Gemini 3.7, dll.
  5. Klik tombol Select untuk mengonfirmasi model yang dipilih.
  6. Klik tombol Start Server (warna orange/merah).

✅ MITM Server berubah dari Stopped menjadi Running — Antigravity terhubung ke 9Router dengan model pilihan!

8

Pilih Combo di Antigravity Settings

Terakhir, pilih combo yang sudah dibuat:

  1. Di Antigravity Editor, buka Settings (ikon roda gigi ⚙️).
  2. Cari bagian Model Selection / AI Provider / 9Router Settings.
  3. Pilih combo OpenCode-AI dari dropdown/selector.
  4. Klik Save / Connect.

✅ SELESAI! Antigravity + 9Router + OpenCode + Combo siap digunakan. Sekarang waktunya bikin website portofolio!

BAB 5 · PUBLIKASI

Apa itu Vercel?

Vercel adalah platform cloud gratis untuk mempublikasikan website. Ia membaca langsung dari repository GitHub, auto-deploy setiap kali kamu push kode, dan memberikan URL publik nama.vercel.app yang bisa diakses dari mana saja.

☁️

Gratis & Cepat

Tanpa biaya sewa hosting. Deploy selesai dalam hitungan menit dengan CDN global.

🔄

Auto Deploy

Setiap push ke GitHub, Vercel otomatis melakukan build ulang. Website selalu terbarui.

🌍

URL Publik

Website bisa dibuka dari HP, laptop, komputer mana pun. Contoh: portfolio-nama.vercel.app.

Langkah 1 — Upload ke GitHub

Di folder proyek, buka Terminal dan jalankan perintah berikut secara berurutan:

git init
git add .
git commit -m "Portfolio Website"
git branch -M main
git remote add origin https://github.com/USERNAME/portfolio-nama.git
git push -u origin main

Langkah 2 — Deploy di Vercel

  1. Buka vercel.com → login dengan akun GitHub.
  2. Klik Add New → Project → pilih repository portfolio-nama.
  3. Klik Deploy → tunggu proses selesai → akan ada animasi confetti 🎉 & URL publik muncul.

Langkah 3 — Dapatkan URL Live

https://portfolio-nama-siswa.vercel.app

✅ Website kamu sudah LIVE! Bisa dibuka dari HP, laptop, komputer mana pun. Tempel link-nya ke tugas portofolio.
